# Automovel

## Descrição

O **Automovel** é uma aplicação de gestão de oficinas automóveis, desenvolvida com o objetivo de centralizar e simplificar a gestão dos diferentes processos associados ao funcionamento de uma oficina.

A aplicação permite gerir a informação relativa a clientes, veículos, marcações, mecânicos, reparações e serviços realizados.

O sistema é composto por duas partes principais: **Backend** e **Frontend**, que comunicam entre si para disponibilizar as funcionalidades da aplicação.

## Tema

O projeto tem como tema a **gestão de uma oficina automóvel**.

Uma oficina necessita de gerir diariamente diferentes tipos de informação, desde os dados dos seus clientes e respetivos veículos até às marcações, reparações e serviços realizados.

O sistema pretende organizar este processo, permitindo acompanhar cada veículo desde a marcação de um serviço até à conclusão da respetiva reparação.

Entre as principais operações do sistema encontram-se:

* Gestão de clientes;
* Gestão de veículos;
* Gestão de mecânicos;
* Gestão de marcações;
* Gestão de reparações;
* Registo dos serviços realizados;
* Gestão das peças utilizadas;
* Consulta do histórico de intervenções de um veículo;
* Acompanhamento do estado das reparações.

## Backend

O Backend é responsável por toda a lógica e gestão dos dados da aplicação.

É a componente responsável por receber os pedidos provenientes do Frontend, processar as operações solicitadas, aplicar as regras de negócio e gerir a informação armazenada no sistema.

O Backend disponibiliza os serviços necessários para que o Frontend possa realizar operações como criar clientes, registar veículos, marcar serviços, consultar reparações e atualizar o estado de uma intervenção.

Desta forma, o Backend funciona como a camada responsável pelo funcionamento interno da aplicação e pela comunicação com os dados do sistema.

## Frontend

O Frontend é a componente responsável pela interação com o utilizador.

Através da interface disponibilizada, os diferentes utilizadores podem consultar e gerir a informação da oficina de forma simples e organizada.

O Frontend permite, entre outras funcionalidades:

* Consultar clientes e os seus veículos;
* Criar e gerir marcações;
* Consultar reparações;
* Acompanhar o estado dos serviços;
* Gerir informação relacionada com mecânicos;
* Consultar o histórico de intervenções;
* Consultar a informação necessária para a gestão diária da oficina.

O Frontend comunica com o Backend para obter e atualizar a informação apresentada ao utilizador.

## Testes

O projeto inclui uma componente de testes destinada a garantir o correto funcionamento das diferentes funcionalidades da aplicação.

Os testes permitem verificar o comportamento esperado do sistema, identificar erros e garantir que as operações relacionadas com a gestão da oficina funcionam de acordo com as regras definidas.

São considerados testes para diferentes áreas da aplicação, incluindo a gestão de clientes, veículos, marcações e reparações, bem como as respetivas regras de negócio.

## Objetivo

O principal objetivo do projeto é desenvolver uma solução que permita **digitalizar e organizar a gestão de uma oficina automóvel**, facilitando o acompanhamento dos veículos, serviços e reparações e centralizando a informação necessária ao funcionamento da oficina.
